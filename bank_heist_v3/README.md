# 2.5D Bank Robbery Mission v3.0 (100% Code-Rendered — Skill ZIP v3.0 Showcase)

A **10.00-second (`300 frames @ 30.00 FPS`), `1080×1920` (9:16), silent (`0 audio streams`), caption-free** 2.5D animated Bank Heist Short built 100% from code using **Skill ZIP v3.0**:
- **Zero Flat-Color 3D Meshes:** Every surface carries procedural tri-channel PBR (`map` + `bumpMap` + `roughnessMap`) — veined emerald & ivory checkered marble, Art-Deco limestone/mahogany walls, 64 numbered brushed-steel & brass safety deposit lockers, riveted steel & brass circular Bank Vault Door, engraved brass combination dial, beveled gold bullion bars, strapped `$10K` cash stacks, wooden crates, and woven velvet ropes.
- **Blender-Freestyle 3D Ink Outlines + Real-Time `PCFSoftShadowMap` Shadows + Organic Paper Tooth.**
- **Multi-Angle Painterly Characters (`heist_rigs.js`):** Master Thief (ribbed burglar beanie, emerald NV goggles, layered hair tufts, woven charcoal trenchcoat, striped shirt, leather harness, `$` loot sack, gold bar) & Deadpan Night Security Guard (woven navy uniform, gold badge, walrus mustache, peaked cap, yellow flashlight & half-eaten pink sprinkled donut!).

## Usage

npm install
node render_heist.mjs --gates   # Stage 4B full-res 5-scene visual & detail audit
